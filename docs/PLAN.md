# HolyPop 구현 계획

## 빠른 일시 중지

아이콘 클릭 메뉴에 30분·1시간·2시간·4시간·8시간 동안 꺼짐, 지금 재개, 설정 화면 열기, 종료하기를 제공한다. 일시 중지는 현재 오버레이와 준비 중 표시를 취소하며 기존 설정의 자동 표시 값을 변경하지 않는다. 종료 시각은 잠자기 중에도 경과하는 시스템 시각으로 계산한다. 만료·재개 후 간격을 새로 시작하며 앱 재시작 시 일시 중지는 해제한다. 수동 미리보기는 계속 허용한다. 추가 타이머 스레드 없이 기존 예약 루프를 사용한다.

## 상주 동작 변경 — 2026-11-20

최소화·닫기는 앱 종료 대신 창 숨김으로 처리한다. macOS는 메뉴바 템플릿 아이콘을 유지하고 숨김 시 Dock에서 제외한다. Windows는 작업표시줄 알림 영역의 앱 아이콘을 유지한다. 두 플랫폼 모두 아이콘 메뉴에 설정 열기·종료를 제공한다. 복원 순서는 최소화 해제, 창 표시, 포커스 요청이다. macOS 최소화는 네이티브 알림, Windows는 최소화에 따른 창 크기 이벤트에서 처리하며 추가 폴링은 하지 않는다.

## 표시 확장

- 스타일: 글자만, 그림자, 글래스, 반투명, 컬러박스. 배경색과 글자색을 설정한다. 글래스는 CSS 유리 질감이며 다른 앱의 화면을 실제로 블러 처리하지 않는다.
- 모니터: 기본, 설정 창이 있는 화면, 지정한 화면, 전체 화면에 동일 구절을 각각 표시한다. 특정 화면을 분리하면 기본 화면으로 대체한다.
- 크기: 각 모니터의 가로·세로 대비 백분율로 표시 영역을 제한한다. 글자 크기와 상·중·하 위치는 독립 설정한다.
- 호환: 기존 설정 파일에 새 항목이 없어도 자동으로 기본 표시 설정을 채운다. 기존 구절·예약은 유지한다.
- 검증 조건: 구형 설정 복원, 범위·색상 검증, 모니터 선택과 분리 시 대체, 추가 창 준비 지연·재표시·종료, 서로 다른 화면 크기에서 영역 비율과 본문 넘침을 검사한다.

## 실제 역할 배정

요청한 6.1 Astra와 5.6 Sol은 이 세션에서 제공되지 않아 계획은 6 Astra, 구현은 6.1 Terra 두 에이전트, 독립 검토·테스트는 6.1 Sol로 진행했다. 현재 주 에이전트가 통합, 화면 검증, 패키지 빌드를 맡았다.

## 목표와 범위

macOS와 Windows에서 성경 구절을 정해진 시간에 표시하는 가벼운 데스크톱 앱을 만든다. Tauri 2와 Rust 백엔드, 별도 프레임워크 없는 HTML·CSS·JavaScript 화면을 사용한다. 설정 창은 800×600 이하이며 아이보리 배경, 짙은 갈색 글자, 기능별 툴팁을 제공한다.

범위는 구절 선택, 번역 필터, 사용자 구절 입력, 표시 효과, 간격·시간대·요일 예약, 설정 저장, 메뉴바/알림 영역 아이콘이다. 계정·클라우드 동기화·온라인 성경 다운로드·JSON 가져오기·지정 시각 예약 모드·추가 UI 프레임워크는 포함하지 않는다.

## 최소 구조

- **Rust 백엔드:** 설정 및 사용자 구절의 읽기·검증·저장, 구절 선택, 예약 판정, 오버레이 창 제어를 담당한다.
- **설정 웹뷰:** 구절·번역·예약·표시 효과를 수정하고 미리보기를 실행한다. 저장 성공 또는 오류를 화면에 명확히 표시한다.
- **오버레이 웹뷰:** 투명하고 테두리가 없으며 항상 위에 표시된다. 포인터 이벤트를 OS 창 수준에서 통과시켜 뒤쪽 앱을 사용할 수 있게 한다. 별도 입력이나 주기적인 데이터 조회를 하지 않는다.
- **파일 저장:** 앱 데이터 디렉터리에 설정과 `custom_verses`를 저장한다. 누락 시 기본값으로 시작하고 잘못된 파일은 보존한 채 오류를 안내한다. 저장 실패 시 기존 데이터가 유지되도록 한다.
- **이벤트 전달:** 백엔드가 표시할 구절과 효과를 오버레이에 전달한다. CSS 애니메이션으로 효과를 처리하고 표시 시간이 끝나면 창을 숨긴다.

역할에 맞는 소수의 파일만 사용한다. 예약 로직은 UI와 분리한 순수 함수로 두어 날짜·시각을 넣는 간단한 테스트가 가능하게 한다. 외부 네트워크 요청 없이 동작하도록 한다.

## 동작 규칙

### 성경 데이터와 구절 선택

- 기본 데이터는 공개 도메인 World English Bible(WEB)의 소량 샘플이며, 전체 성경이 아니라는 점을 화면에 표시한다. 샘플 출처와 사용 조건을 문서에 남긴다.
- 사용자 구절은 `custom_verses` 배열에 저장한다. 각 항목은 성경 위치 `reference`, 본문 `text`, 번역명 `version`을 가진다. 빈 필수 값과 과도한 입력은 거부한다.
- 번역 선택은 구절의 `version`을 기준으로 목록을 필터링한다. 선택 결과가 비었거나 직접 선택한 구절이 필터 밖이면 잘못된 본문을 표시하지 않고 유효한 선택을 안내한다.
- `오늘의 말씀`은 같은 로컬 날짜와 번역에서 자동으로 고정한다. 사용자는 `직접 선택`으로 오늘 기억할 구절을 지정할 수 있다. `무작위`는 표시 시 선택한 번역의 목록에서 구절을 고른다.
- 출처가 불명확한 전문 데이터를 앱에 포함하지 않는다. 사용자가 입력한 구절은 로컬에 보관한다.

### 예약

- 예약은 `interval_minutes` 간격에 `start_time`·`end_time` 시간대와 `weekdays` 요일을 함께 적용한다. 예약 사용 여부와 미리보기는 독립적이다.
- 간격은 유효한 양수 범위로 검증한다. 시작·종료 시각은 로컬 시각 `HH:MM`으로 검증한다. 활성 예약은 적어도 하나의 요일을 요구한다.
- 선택한 요일·시간대 안에서만 간격에 따라 표시한다. 같은 예약 확인 주기에 중복 표시하지 않는다. 자정을 지나는 시간대의 처리 규칙은 구현과 안내가 일치해야 한다.
- 앱 시작·절전 복귀 후 과거 예약을 연속 재생하지 않는다. 다음 유효한 예약부터 동작하며 앱이 종료된 동안에는 실행하지 않는다.
- 구절이 표시되는 동안 새 표시 요청이 오면 기존 표시를 교체하고 표시 종료 타이머를 다시 시작한다.

### 표시와 자원 사용

- 효과는 페이드, 슬라이드, 팝, 스크롤을 제공하며 공통 표시 시간이 적용된다. 모션 감소 설정이 활성화된 환경에서는 움직임을 최소화한다.
- 예약 확인은 Rust의 단일 저빈도 타이머로 수행한다. 웹뷰별 반복 폴링이나 숨겨진 창의 지속 애니메이션을 사용하지 않는다.
- 설정 창 최소화·닫기 시 창을 숨긴다. macOS 메뉴바와 Windows 작업표시줄 알림 영역 아이콘 메뉴에서 설정을 복원하거나 종료한다. 예약은 유지하며 명시적인 앱 종료 후에는 백그라운드 실행이 남지 않는다.
- 플랫폼별 투명도·클릭 통과·항상 위 표시 동작은 실제 macOS와 Windows에서 각각 확인한다.

## 구현 순서

1. Tauri 앱, 두 창, 기본 색상과 크기, 플랫폼별 닫기·복원을 구성한다.
2. 샘플 구절과 설정 모델, 유효성 검증 및 저장·복원을 구현한다.
3. 번역 필터·구절 선택과 사용자 구절 입력을 연결한다.
4. 오버레이 표시, 클릭 통과와 네 가지 효과를 구현한다.
5. 간격·시간대·요일을 적용하는 예약 판정 및 중복 방지를 연결한다.
6. 핵심 로직 테스트, 로컬 빌드, 실제 창 동작 검증을 수행한다.

## 인수 조건

| 항목 | 통과 조건 |
| --- | --- |
| 시작·설정 | 새 설치에서 오류 없이 시작하고 설정 창이 800×600을 넘지 않는다. 키보드로 설정을 조작할 수 있고 툴팁 또는 설명을 확인할 수 있다. |
| 저장·복원 | 설정 변경 후 재실행해도 같은 값이다. 저장 실패를 성공으로 안내하지 않으며 손상된 입력 파일은 보존한다. |
| 구절 | 오늘의 말씀은 같은 날짜에 일정하고, 직접 선택은 유지되며, 무작위 결과는 선택 번역의 목록 안에 있다. |
| 사용자 구절 | `reference`·`text`·`version` 입력과 저장이 가능하고 번역 필터에 반영된다. 빈 필수 값과 범위 초과 입력은 기존 구절 손실 없이 거부한다. |
| 간격·요일 | 활성 요일에만 간격 실행한다. 비활성 요일과 예약 비활성 상태에서는 자동 표시하지 않는다. |
| 시간대 | 시작·종료 시각에 따른 허용 시간대 밖에서는 자동 표시하지 않는다. 절전 복귀 후 누락된 표시를 몰아서 실행하지 않는다. |
| 오버레이 | 배경이 투명하고 다른 창 위에 나타나며 오버레이 위를 눌러도 뒤쪽 앱이 입력을 받는다. 표시 시간이 지나면 숨겨진다. |
| 효과 | 페이드·슬라이드·팝·스크롤 모두 구절을 읽을 수 있고 새 표시가 이전 타이머에 의해 조기에 종료되지 않는다. |
| 생명주기 | 최소화·닫기 후 예약을 유지한다. Windows 알림 영역과 macOS 메뉴바 아이콘 메뉴로 설정 창을 복원한다. 완전 종료하면 예약과 프로세스가 종료된다. |
| 플랫폼·자원 | macOS와 Windows에서 각각 빌드와 실제 창 동작을 확인한다. 대기 중 반복 네트워크 요청·연속 애니메이션·과도한 CPU 사용이 없다. |

예약 경계값과 중복 방지, 잘못된 사용자 구절, 날짜별 구절 선택은 작은 단위 테스트로 검증한다. 구체 절차는 [TESTS.md](TESTS.md)에 기록한다. 이 문서는 구현·검증 계획이며 코드 테스트 통과를 의미하지 않는다. 다른 운영체제의 실행 검증이나 서명·배포를 수행하지 못했다면 완료 보고에서 명확히 구분한다.
