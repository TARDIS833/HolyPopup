# HolyPop

화면 위에 말씀만 잠깐 띄우는 성경 암송 앱. Rust + Tauri 2, macOS·Windows 지원을 목표로 합니다. 설정 화면만 HTML·CSS·JavaScript이며 UI 프레임워크와 Node 패키지는 사용하지 않습니다.

## 사용

1. **말씀**에서 번역과 구절을 선택하거나 직접 입력합니다.
2. **예약**에서 요일, 활성 시간대, 반복 간격을 정합니다.
3. **화면**에서 글자 크기, 불투명도, 효과, 배경 스타일과 색상을 고릅니다.
4. **배치**에서 표시할 모니터, 영역의 가로·세로 비율과 위치를 고릅니다.
5. 미리보기로 확인한 뒤 저장합니다.

오늘의 말씀은 날짜별로 고정되고, 직접 선택은 고른 구절을 계속 표시합니다. 무작위는 선택한 번역의 등록 구절에서 고릅니다. 오늘 외우고 싶은 특정 말씀은 직접 선택으로 지정하면 됩니다.

설정 창을 최소화하거나 닫아도 예약은 유지됩니다. macOS는 상단 메뉴바 아이콘, Windows는 작업표시줄 오른쪽 알림 영역 아이콘에서 **설정 화면 열기**로 돌아옵니다. Windows에서 아이콘이 숨겨져 있으면 알림 영역의 위쪽 화살표를 확인하세요. 완전히 끝내려면 아이콘 메뉴의 **종료하기** 또는 설정 창의 **종료**를 사용합니다. 앱이 실행 중일 때만 예약이 동작하며 잠자기 중 놓친 구절을 몰아서 표시하지 않습니다.

아이콘을 클릭하면 빠른 설정 메뉴가 열립니다. **30분·1시간·2시간·4시간·8시간 동안 꺼짐**을 선택하면 현재 말씀을 숨기고 자동 표시를 잠시 멈춥니다. 다른 시간을 고르면 그 시점부터 다시 계산하며, **지금 재개**로 취소할 수 있습니다. 만료 또는 재개 후에는 설정된 반복 간격을 다시 기다리고 요일·시간대 조건을 적용합니다. 설정에서 자동 표시를 꺼 둔 경우 이를 강제로 켜지 않습니다.

일시 중지는 잠자기 시간을 포함하며 앱을 완전히 종료했다 다시 실행하면 해제됩니다. 일시 중지 중에도 수동 미리보기는 사용할 수 있습니다.

## 다운로드·GitHub 빌드

배포 빌드는 GitHub Actions에서 진행합니다. `main`에 푸시하거나 [Build HolyPop](https://github.com/TARDIS833/HolyPopup/actions/workflows/check.yml)의 **Run workflow**를 누르면 테스트 후 설치 파일을 생성합니다. Pull Request에서도 같은 검증을 실행합니다.

GitHub에 로그인한 뒤 성공한 실행을 열고, 하단 **Artifacts**에서 운영체제에 맞는 ZIP을 다운로드해 압축을 풉니다. 파일은 실행일로부터 30일간 보관됩니다.

| Artifact 이름 | 설치 파일 |
| --- | --- |
| `HolyPop-Windows-x64-커밋번호` | Windows x64 설치 프로그램 `.exe` |
| `HolyPop-macOS-AppleSilicon-커밋번호` | M 시리즈 Mac용 `.dmg` |
| `HolyPop-macOS-Intel-커밋번호` | Intel Mac용 `.dmg` |

DMG를 열어 HolyPop을 Applications로 옮깁니다. 현재 배포물은 코드 서명·Apple 공증이 없는 테스트용입니다. macOS 보안 설정의 실행 허용 또는 Windows SmartScreen 확인이 필요할 수 있습니다.

## 개발·검증

Rust stable과 운영체제별 [Tauri 개발 환경](https://v2.tauri.app/start/prerequisites/)이 필요합니다. macOS는 Xcode Command Line Tools, Windows는 MSVC Build Tools와 WebView2가 필요합니다.

```sh
cargo run --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo clippy --manifest-path src-tauri/Cargo.toml --locked -- -D warnings
node --test ui/*.test.mjs
```

설치 파일은 위 GitHub Actions에서 생성합니다. 원격 실행 결과는 Actions 실행 기록, 기능별 검증 범위는 [검증 기록](docs/TESTS.md)을 확인하세요.

## 데이터와 범위

기본 데이터는 **WEB 영문 일부 구절**이며 전체 성경이 아닙니다. WEB는 [공식 배포처에서 공개 도메인으로 제공](https://www.ebible.org/eng-web/copyright.htm)합니다. 한글 등 다른 번역은 사용할 권한이 있는 본문과 번역명을 직접 입력합니다. 번역 전문 다운로드, 계정, 동기화, 자동 시작, 자동 업데이트는 포함하지 않습니다.

설정과 입력 구절은 운영체제의 앱 데이터 폴더에 로컬 저장합니다. macOS 경로는 `~/Library/Application Support/com.holypop.app`입니다. 저장할 때마다 새 설정 사본을 생성하고 기존 파일은 보존합니다. 손상된 최신 파일은 건너뛰어 이전 정상 설정을 복구합니다. 자동 정리를 하지 않으므로 저장 사본은 누적됩니다. 앱은 원격 요청을 하지 않습니다.

예약은 최대 30초 간격으로 확인하므로 지정 간격보다 최대 약 30초 늦게 표시될 수 있습니다. 매우 긴 본문은 스크롤을 사용하면 설정한 글자 크기를 유지합니다. 다른 효과에서는 화면에 맞춰 글자를 줄입니다.

모니터는 주 모니터, 현재 화면(설정 창이 있는 화면), 특정 모니터 또는 모든 모니터를 선택할 수 있습니다. 모든 모니터에서는 같은 구절을 각 화면에 별도로 표시합니다. 선택한 화면이 분리되면 주 모니터로 대체합니다. 새로 연결한 화면은 배치 탭에서 새로고침하면 목록에 나타납니다.

영역 너비·높이는 각 모니터의 10~100%로 조절합니다. 글자 크기와 독립된 제한 영역이며 긴 구절은 그 안에 맞춰 축소하거나 스크롤합니다. 여러 화면의 해상도와 배율은 운영체제 값을 사용합니다. 이름이 같은 모니터들의 배치를 바꾸면 특정 모니터 선택을 다시 확인하세요.

배경 없음·그림자·유리·반투명·단색 스타일을 제공합니다. 유리는 반투명 그라데이션과 테두리로 표현하며 다른 앱 화면의 실제 블러는 지원하지 않습니다. 모든 모니터를 사용하면 모니터별 웹뷰가 추가되어 단일 화면보다 메모리를 더 사용합니다.

다른 앱의 독점 전체화면, 보안 화면 위의 표시는 보장하지 않습니다. 배포용 코드 서명과 공증은 별도입니다.
